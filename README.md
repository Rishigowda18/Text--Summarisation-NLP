# Text Summarisation Using NLP

## Project Overview
This project converts lengthy text into shorter and meaningful summaries using Natural Language Processing (NLP).

## Objectives
- Reduce lengthy text.
- Identify important sentences.
- Save reading time.
- Preserve the original meaning.

## Technologies Used
- Python
- Natural Language Processing (NLP)
- TF-IDF
- Scikit-learn
- Google Colab

## Methodology
1. Input the original text.
2. Split text into sentences.
3. Convert sentences into TF-IDF vectors.
4. Calculate sentence importance scores.
5. Select important sentences.
6. Generate the final summary.

## How to Run
1. Open the notebook in Google Colab.
2. Run all code cells.
3. View the generated summary.
